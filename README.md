# mini-flux

Aplicación web inicializada con Vite, React y TypeScript como proyecto base del semillero de desarrollo de software.

## Requisitos previos

Para poder empezar, debemos tener lo siguiente en nuestro equipo:

- **Node.js** (versión LTS)
- **pnpm** instalado globalmente (`npm install -g pnpm`)
- **Git** configurado con tu usuario y correo

## Instalación y puesta en marcha

1. Clona el repositorio en tu máquina:

   ```bash
   git clone [https://github.com/GoGoCatrina/mini-flux.git](https://github.com/GoGoCatrina/mini-flux.git)
   ´´´

Para esto, es muy importante trabajar con el CMD.

## Abre la consola de tu maquina e inserta los siguientes comandos:

- Para entrar a la carpeta del proyecto:
cd mini-flux 

- Para la instalación de las dependencias:
pnpm install

- Para iniciar el servidor de desarrollo
pnpm dev

## Como siguiente paso, abriremos en nuestro navegador la dirección local que muestra nuestra consola (por lo regular es http://localhost:5173)
